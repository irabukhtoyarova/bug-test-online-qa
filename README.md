# bug-test-online-qa

Ручное тестирование лендинга [bug-test.online](https://bug-test.online) — песочницы для начинающих QA-специалистов.

## Цель проекта

Демонстрация полного цикла ручного тестирования от анализа требований до итогового отчёта: анализ ТЗ ↔ макеты, тест-дизайн (EP/BVA), чек-листы, тест-кейсы.

## Структура проекта

```
bug-test-online-qa/
├── docs/
│   ├── 01-requirements-analysis.md   ← анализ требований (33 строки реестра)
│   ├── 02-test-design.md             ← тест-дизайн: EP/BVA по полям формы
│   └── 03-checklist.md               ← чек-листы: навигация, форма, адаптив
├── sources/
│   ├── tz/                           ← исходники ТЗ (3 страницы)
│   └── mockups/                      ← исходники макетов (5 страниц)
└── README.md
```

## Источники требований

- Техническое задание (ТЗ) — цель проекта, структура лендинга, форматы данных формы, 9 функциональных требований
- Макеты — лендинг в мобильной ширине, модалка формы, бургер-меню, снек-бар, UI-kit

## Результаты анализа

- Выявлено **33** строки в реестре требований (FR/NFR/STR/FLD/UI)
- **10** расхождений между ТЗ и макетами (навигация, структура блоков)
- **19** открытых вопросов к аналитику (тексты ошибок, форматы, поведение UI)
- **30** временных допущений с оценкой рисков

## Окружение

- ОС: Windows 10 IoT Корпоративная LTSC (21H2)
- Chrome 150.0.7871.101 (64 бит) — полный цикл
- Яндекс.Браузер 26.8.0.1788 (64-bit) — smoke
- Экраны: 1920 (десктоп), 1366 (ноутбук), 768 (планшет), 375 (мобильная), 320 (граничное) — DevTools

## Статус

Проект в стадии анализа и тест-дизайна. Сайт недоступен на момент проверки (август 2026) — артефакты подготовлены по ТЗ и макетам, прогон тестов запланирован после восстановления.
