# SQL: Собаседник — MySQL

Учебная БД для интернет-магазина Собаседник.

## Структура

```
sql/
├── schema.sql          ← схема 3 таблиц (products, users, carts)
├── seed.sql            ← тестовые данные
├── queries.sql         ← 7 запросов
└── README.md
```

## Как посмотреть

Результат каждого запроса — в `queries.sql` (таблица с результатами под запросом).

Для запуска онлайн: открыть https://www.db-fiddle.com/f/wrmRdgNTtVwCm8xY5H1KTU/2 → нажать Run.

## Запросы

| # | Приём | Задача |
|---|---|---|
| Q1 | WHERE | Товары «Нет в наличии» |
| Q2 | JOIN + WHERE | Корзина пользователя Анна |
| Q3 | ORDER BY + LIMIT | Топ-3 дорогих товара |
| Q4 | LIKE | Поиск по названию «капитан» |
| Q5 | BETWEEN | Товары в диапазоне 500–1100 ₽ |
| Q6 | GROUP BY + COUNT | Сколько товаров с каждым бейджом |
| Q7 | LEFT JOIN + IS NULL | Товары, которые никто не добавлял в корзину |
